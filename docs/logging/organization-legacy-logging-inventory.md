## Scope and method

- Repository enumeration came from the GitHub organization API with `type=all`; private repositories and forks were included.
- Every repository was shallow-cloned at the exact default-branch commit recorded under [Scan coverage](#scan-coverage).
- Compiled C/C++ sources and headers were scanned for `\b(LOG|VLOG|PLOG)\s*\(`.
- Maintained SNode.C code examples in Markdown, TeX, and the Express compatibility patch were included because they still teach or materialize the legacy API.
- Comment-only mentions, string literals used by policy tests, historical semantic-migration reports, and prose that merely names the macros were excluded.
- Generated Doxygen HTML in `mqttsuite-doc` and `snode.c-doc` was excluded: those repositories must be regenerated from migrated source rather than edited as call sites.
- Same-spelled macros belonging to unrelated upstream logging systems were excluded. In particular, matches in the `termux-packages` fork are Android/Chromium/GDB-style logging, not the SNode.C legacy facade.
- Line numbers are exact for the recorded commits and will move when source files change.
