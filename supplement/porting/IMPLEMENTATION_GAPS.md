# Implementation gaps

This is a first implementation proposal, not a complete copy/paste port. The source inventory has 163 entries; 58 platform cells have no complete body. Bodies that exist can still have narrower scope than the original call. This list distinguishes absent implementations from draft restrictions; neither category is verified portability.
